# Roadmap

This is planned work, not a list of completed features or external requests.

- [ ] Measure startup time, memory and frame time on a documented desktop and mobile device.
- [ ] Add browser smoke checks for opening books, turning pages and returning to the room.
- [ ] Improve keyboard focus and provide a visible object list for users who cannot target a 3D object.
- [ ] Split scene setup, content loading and interaction state into smaller modules.
- [ ] Replace legacy asset identifiers with neutral names in a documented compatibility update.
- [ ] Add a small example showing how to supply new book content without editing scene code.
- [ ] Collect feedback from real users and record reproducible problems in issues.

Priority follows actual usability problems and available maintenance time. Dates and adoption targets are intentionally not promised.
