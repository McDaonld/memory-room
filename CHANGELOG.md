# Changelog

## 0.1.0 — 2026-10-08

Initial public edition prepared from the author's private interactive desk prototype.

- Added a complete local distribution with neutral sample books, documents and illustrations.
- Removed embedded source photographs from public models and replaced game/character material with generic geometry.
- Preserved book reading, object inspection, desk-computer and room navigation interfaces.
- Added a dependency-free local server, package verification and regression tests.
- Documented asset licensing, customization, contribution workflow and maintenance scope.

This is the start of the public project, not a reconstruction of earlier public release history.
