# Maintainer

**Primary maintainer: [McDaonld](https://github.com/McDaonld).**

Memory Room is an author-led project with an initial public edition prepared in October 2026. The maintainer defines the product direction, approves what is published and is responsible for future releases, incoming issues and contribution review. The implementation and public-release preparation use AI assistance.

## Current scope

This release turns a private desk prototype into a reusable example: it replaces personal and third-party material, provides local startup instructions, documents asset provenance and includes checks for core geometry behavior and package integrity.

This file does not claim years of public maintenance, external users, third-party contributions, or completed issue/PR reviews. Those should be evaluated from the public repository's real activity as the project develops.

## Working practice

- Track reproducible defects and feature proposals in issues.
- Review new assets for source and redistribution terms.
- Keep releases tied to actual changes and verification results.
- State limits openly, especially untested devices and incomplete accessibility support.
- Update the roadmap as real feedback arrives; do not create artificial issues or contributions to suggest popularity.

Contact for ordinary project questions: open an issue in this repository. Do not post passwords, personal documents or other private information in public issues.
